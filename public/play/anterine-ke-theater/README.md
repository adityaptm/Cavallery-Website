# Anterin Erine ke Theater

Game platformer web 2 pemain fan-made: Bantu Erine (member JKT48 Team Passion) melewati berbagai rintangan untuk mencapai portal Theater JKT48 sebelum pertunjukan dimulai!

> **Catatan:** Game ini adalah karya fan-made non-komersial dan tidak berafiliasi resmi dengan JKT48.

## Kontrol Permainan
- **Player 1 (Erine)**:
  - Bergerak: Tombol Panah Kiri (`←`) / Kanan (`→`)
  - Lompat: Tombol Panah Atas (`↑`)
- **Player 2 (Pengantar)**:
  - Bergerak: `A` / `D`
  - Lompat: `W`
- **Mute / Unmute**: Tombol speaker di pojok layar
- **HP / Layar Sentuh**: Tersedia touch controls di bagian bawah layar

## Fitur Utama
1. **Co-op 2 Pemain**: Kedua pemain harus bekerja sama membuka pintu gerbang dan mencapai portal bersama-sama untuk menyelesaikan level.
2. **3 Level Bertahap**: Desain rintangan bertingkat (level 1, 2, dan 3).
3. **Audio & Musik**: BGM tema dan efek suara (lompat, ambil diamond/api, buka/tutup gerbang, kena rintangan, naik level, game over).
4. **Pilihan Karakter Player 2**: Bisa memilih pengantar Cowok atau Cewek.
5. **Animasi Loading**: Animasi lari Erine Passion dengan progress bar 0% - 100%.

## Teknologi
- Vanilla JavaScript & HTML5 Canvas
- Phaser 3 (Arcade Physics)
- Web Audio API & HTML5 Audio
- Boxicons
